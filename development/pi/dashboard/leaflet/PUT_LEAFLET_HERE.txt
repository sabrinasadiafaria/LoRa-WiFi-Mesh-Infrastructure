Leaflet is vendored locally so the dashboard works with no internet.

On the Pi, once, with internet:

    cd development/phase\ 5/pi/dashboard/leaflet
    curl -LO https://unpkg.com/leaflet@1.9.4/dist/leaflet.js
    curl -LO https://unpkg.com/leaflet@1.9.4/dist/leaflet.css
    curl -LO https://unpkg.com/leaflet@1.9.4/dist/images/marker-icon.png
    curl -LO https://unpkg.com/leaflet@1.9.4/dist/images/marker-shadow.png
    mkdir -p images && mv marker-icon.png marker-shadow.png images/

index.html references  leaflet/leaflet.js  and  leaflet/leaflet.css .
(The node markers use L.divIcon, so the marker PNGs are only needed if you
add default markers later.)
